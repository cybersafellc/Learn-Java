# Java Data Types
In java we are must declare the specific type a variable.

Two categorys of type in java :

## Primitive Data Type
- byte
- short
- int
- long
- float
- double
- char
- boolean

## Non-Primitive Data Type
- String
- Arrays
- Class
## ``var`` Keyword

this is to allow the compiler for automactly chose a type

```java
var isAllow = true; // automactly = boolean isAllow = true;
```
