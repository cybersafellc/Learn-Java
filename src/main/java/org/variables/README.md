# Multiple Variable
## Declare Multiple Variable
- you can declare multiple variable in one type
```java
int x, y, z;
x = 10;
y = 20;
z = 30;
```
## one value to multiple variable
- you can add one value to many of variables
```java
int x, y, z;
x = y = z = 20;
```
